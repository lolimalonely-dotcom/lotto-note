# คีย์เลข (lotto-note)

เว็บช่วยคีย์รายการเลขให้ไวขึ้น — พิมพ์รหัสกับจำนวนในช่องเดียว ระบบเลือกประเภทให้อัตโนมัติ
พร้อมปุ่มกลับเลข และแดชบอร์ดสรุปยอดต่อรายการ/ต่อเลข

Next.js 16 · React 19 · Tailwind v4 · Supabase

---

## กฎประเภท

| จำนวนหลักของรหัส | ประเภทที่เป็นไปได้     |
| ---------------- | ---------------------- |
| 2 หลัก           | `บ.` (บน) · `ล.` (ล่าง) |
| 3 หลัก           | `ตรง` · `ต.` (โต๊ด)     |

ใส่รหัสปุ๊บ ตัวเลือกประเภทก็แคบลงเหลือแค่ 2 ทางทันที กฎนี้บังคับทั้งฝั่งหน้าเว็บ
และฝั่งฐานข้อมูล (CHECK constraint) จึงไม่มีทางบันทึกคู่ที่ผิดกฎลงไปได้

## วิธีคีย์

ตั้ง **ชื่อรายการ** ไว้ด้านบนครั้งเดียว แล้วคีย์เฉพาะ `รหัส จำนวน` รัวได้เลย — กด Enter บันทึกทีละบรรทัด

| พิมพ์          | ได้                                        |
| -------------- | ------------------------------------------ |
| `12 20*30`     | `บ. 12 จำนวน 20` + `ล. 12 จำนวน 30`         |
| `12 20*20`     | `บ. 12 จำนวน 20` + `ล. 12 จำนวน 20`         |
| `123 20*30`    | `ตรง 123 จำนวน 20` + `ต. 123 จำนวน 30`      |
| `12 20`        | ขึ้นให้เลือกประเภท — กด `1` = บ. / `2` = ล.  |
| `12 20 บ`      | ระบุประเภทติดไปในบรรทัดเลย ไม่ต้องกดเลือก    |
| `12 20*`       | ลงแค่ `บ.` ข้างเดียว                        |
| `12 *30`       | ลงแค่ `ล.` ข้างเดียว                        |
| `*123 300`     | กลับเลข → `ตรง` 123 132 213 231 312 321 ตัวละ 300 |
| `123 300 ก`    | เหมือนบรรทัดบน                              |
| `*12 20*30`    | กลับเลข 12 → 12, 21 แต่ละตัวลง บ.20 และ ล.30 |

รายละเอียดเพิ่มเติม

- **ตัวคั่นจำนวน** ใช้ `*` `x` `X` `×` ได้หมด และเว้นวรรครอบตัวคั่นได้ (`12 20 * 30`)
- **แทนเว้นวรรค** ด้วย `#` หรือ `=` ได้ (`12#20*30`) เผื่อคีย์บนแป้นตัวเลขมือถือ
- **เลขไทย** `๑๒ ๒๐*๓๐` ใช้ได้
- **หลักพัน** ใส่ `,` ได้ (`12 1,000`)
- **คำย่อประเภท** `บ`/`บน`/`b` · `ล`/`ล่าง`/`l` · `ตรง`/`s`/`tr` · `ต`/`โต๊ด`/`t`
- **กลับเลข** พิมพ์ `*` นำหน้ารหัส หรือ `ก`/`กลับ`/`p` ต่อท้าย หรือกด `F2` เปิดหน้าต่างกลับเลข
  เลขหลักซ้ำระบบตัดตัวซ้ำให้เอง (`112` → 112, 121, 211 · `11` → 11)
- **จำนวนในการกลับเลข** คือจำนวน **ต่อเลข 1 ตัว** (`*123 300` = ตัวละ 300 รวม 1,800)

### คีย์ลัด

| ปุ่ม            | ทำอะไร                          |
| --------------- | ------------------------------- |
| `Enter`         | บันทึกบรรทัด                     |
| `1` / `2`       | เลือกประเภทตอนระบบถาม            |
| `Esc`           | ล้างช่องคีย์ / ปิดหน้าต่าง        |
| `F2`            | เปิดหน้าต่างกลับเลข               |
| `Ctrl` + `Z`    | เลิกทำชุดที่บันทึกล่าสุด          |

## แดชบอร์ด

- **ตามรายการ** — ยอดรวมของแต่ละชื่อ แยกย่อยตามประเภท กดขยายดูทุกบรรทัดในบิลได้
- **ตามเลข** — ยอดรวมต่อเลขจากทุกชื่อรวมกัน เรียงมากไปน้อย ใช้ดูว่าเลขไหนรับหนัก
- ส่งออก CSV (เปิดใน Excel ได้เลย ภาษาไทยไม่เพี้ยน) และสั่งพิมพ์ได้

ข้อมูลทั้งหมดแยกตาม **งวด** — เปลี่ยนงวดได้ที่มุมขวาบน ค่าเริ่มต้นคือวันที่วันนี้

## รันในเครื่อง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

ถ้ายังไม่ตั้งค่า Supabase แอปจะวิ่ง **โหมดออฟไลน์** เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์
(มีป้าย "ออฟไลน์" กำกับที่มุมซ้ายบน) — ใช้งานได้ครบทุกฟีเจอร์ แค่ข้อมูลอยู่เฉพาะเครื่องนั้น

## ต่อ Supabase

1. สร้างโปรเจกต์ใหม่ที่ [supabase.com](https://supabase.com)
2. เปิด **SQL Editor** วางไฟล์ [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql) ทั้งไฟล์ แล้วกด Run
3. ไป **Authentication → Users → Add user** สร้างบัญชีของตัวเอง (ติ๊ก *Auto Confirm User*)
   — แอปตั้งใจไม่เปิดให้สมัครเองหน้าเว็บ เพราะ URL เป็นสาธารณะ
4. คัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ค่าจาก **Project Settings → API**

   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
   ```

5. `npm run dev` ใหม่ — จะมีหน้าเข้าสู่ระบบขึ้นมาแทน

**ความปลอดภัย** — ทุกแถวผูกกับ `user_id` และเปิด Row Level Security ไว้ แต่ละบัญชีจึงเห็นและแก้ได้
เฉพาะข้อมูลของตัวเอง การบังคับใช้อยู่ที่ฝั่ง Postgres ไม่ใช่ฝั่งเบราว์เซอร์

## Deploy ขึ้น Vercel

1. push โปรเจกต์ขึ้น GitHub
2. ที่ Vercel กด **Add New → Project** แล้วเลือก repo นี้ (Next.js ตรวจเจอ preset เองอัตโนมัติ)
3. ใส่ Environment Variables สองตัวข้างบนให้ครบทั้ง Production / Preview / Development
4. Deploy

## โครงสร้างโค้ด

```
src/lib/parse.ts      ← ตัวแปลงบรรทัดที่พิมพ์ → รายการที่จะบันทึก (หัวใจของแอป)
src/lib/permute.ts    ← สร้างเลขกลับ ไม่ซ้ำ
src/lib/rules.ts      ← กฎ 2 หลัก / 3 หลัก และป้ายประเภท
src/lib/summary.ts    ← รวมยอดสำหรับแดชบอร์ด + CSV
src/lib/store.tsx     ← ชั้นข้อมูล สลับ localStorage / Supabase อัตโนมัติ
src/components/       ← หน้าจอคีย์ หน้าต่างกลับเลข แดชบอร์ด
supabase/migrations/  ← สคีมา + RLS
```

`parse.ts` เป็นฟังก์ชันบริสุทธิ์ล้วน ไม่พึ่ง React — แก้กฎการคีย์ที่ไฟล์นี้ไฟล์เดียวจบ
